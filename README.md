## Project scope

Borneo.net, an internet provider in south borneo
that sells home fiberoptics plans and handles installation, billing, and outages.

**Goals**

1. Answer customer FAQs about plans, billing, installation and outages, 
and show which FAQ each answer came from.
2. Handle messy input: slang, typos, mixed Indonesian - English, and
Banjarnese mixed with indonesian.
3. Say "I'm not sure" and offer a human agent instead of guessing when the 
answer isn't in the knowledge base.
